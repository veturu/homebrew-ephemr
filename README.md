# Ephemr Homebrew tap

Homebrew formulae for the [Ephemr](https://ephemr.io) CLI and MCP server.

## Install

```sh
brew install veturu/ephemr/ephemr        # the `ephemr` command-line tool
brew install veturu/ephemr/ephemr-mcp    # the MCP server used by Claude
                                         # Desktop, Cursor, Codex, etc.
```

Or tap first for shorter install commands:

```sh
brew tap veturu/ephemr
brew install ephemr ephemr-mcp
```

## Upgrade

```sh
brew upgrade ephemr ephemr-mcp
```

## About

Formulae in this repo are **generated automatically** by the release
workflow in <https://github.com/veturu/ephemr>. They track the latest
tagged release. Do not edit them by hand — your changes will be
overwritten on the next release.

Source code, issue tracking, and release notes live in the main repo:
<https://github.com/veturu/ephemr>.
